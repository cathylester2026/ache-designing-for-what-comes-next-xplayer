# Designing for What Comes Next · xPLAYER

Local/mock multiplayer prototype for facilitated testing. No backend, accounts, or realtime service is connected yet.

## Prototype routes
- Participant join and private vote
- Facilitator session and reveal
- Shared capability selection
- Future-care priority voting
- Shared design brief

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
